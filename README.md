# Healthcare IT & Medical Systems Lab

An independent educational portfolio by Marco Brandt. Open `index.html` in a browser or publish the directory as a static GitHub Pages site. No dependencies, server, or API keys required.

## Modules
- Imaging workflow with failure injection and synthetic events
- Simplified HL7 v2 message inspection and example checks
- Searchable DICOM metadata and study hierarchy
- Four interactive troubleshooting scenarios
- Medical device security review checklist
- Session operations dashboard
- Process improvement calculator

All data is synthetic. No real clinical connections, production architecture, patient data, protocol implementation or clinical decision support. HL7 and DICOM examples illustrate concepts and are not formal conformance tests. No data is sent to a server by the application. Session state resets on reload. External reference links are optional.

## Publishing
Create a repository (e.g. `Healthcare-IT-Lab`), place `index.html` and this README in the root, and enable GitHub Pages from the main branch in repository settings.
